# Mapa Conceptual Interactivo: Computación en la Nube ☁️
(https://view.genially.com/691ccf01a2d82938bbef4a57/interactive-content-computacion-en-la-nube)
Este repositorio contiene un **mapa conceptual interactivo** desarrollado con Genially, que explora los conceptos fundamentales de la **computación en la nube**: tipos de nube, modelos de servicio y proveedores principales.

## 🔍 ¿Qué puedes ver?

- **Tipos de Nube**: Pública, Privada, Híbrida y Comunitaria.  
- **Modelos de Servicio**: IaaS, PaaS y SaaS.  
- **Proveedores de Nube**: AWS (Amazon Web Services), Azure (Microsoft), Google Cloud Platform y Oracle Cloud.

## ✨ Cómo usar el mapa

1. Abre el mapa conceptual con el siguiente enlace:  
   [Ver mapa conceptual de la nube]  (https://view.genially.com/691ccf01a2d82938bbef4a57/interactive-content-computacion-en-la-nube)  
2. Navega por los distintos bloques del mapa.  
3. Haz **clic** sobre los objetos interactivos (cuadros, iconos, botones) para desplegar más información sobre cada tema.

## 💡 Por qué es interactivo

La interactividad permite profundizar en los conceptos sin sobrecargar visualmente el mapa. Cada clic revela definiciones, ejemplos y detalles relevantes, lo que mejora la comprensión y facilita el estudio.

## 🧰 Tecnologías usadas

- [Genially](https://www.genially.com/): herramienta para crear presentaciones y contenido interactivo.  
- Diseño con iconos, colores y nodos para estructurar la información de forma clara y atractiva.

## 📚 ¿Para quién es este recurso?

Este mapa conceptual es ideal para estudiantes, docentes o cualquier persona interesada en aprender los fundamentos de la computación en la nube de manera visual y dinámica.
